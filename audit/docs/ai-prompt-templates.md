# 审计报告 AI 分析提示词方案

## 使用流程

1. **生成审计报告**
   ```bash
   python3 audit/bin/audit repo repos/augmn/<repo-name> --format json
   ```

2. **使用提示词分析** - 复制下面的提示词到对话框，Claude Code 会自动读取并分析 report.json

---

## 提示词模板

### 1. 审计报告解读

```
请分析审计报告 reports/augmn/<repo-name>/latest/report.json，生成详细的解读报告，包含：

1. **执行摘要**
   - 关键发现（Top 5 问题）
   - 风险评估（高/中/低）
   - 整体代码质量评分（1-10）

2. **问题分类分析**
   - 安全漏洞数量和严重程度
   - 代码质量问题分布
   - 性能问题（如有）
   - 代码风格问题

3. **修复优先级建议**
   - 必须立即修复的问题（CRITICAL/HIGH）
   - 建议尽快修复的问题（MEDIUM）
   - 可以延后处理的问题（LOW/INFO）

4. **关键问题详解**
   - 针对 Top 5 最严重的问题，详细说明：
     - 问题原因
     - 潜在影响
     - 修复方法

5. **总体建议**
   - 代码质量改进方向
   - 安全加固建议
   - 最佳实践推荐

输出格式：Markdown
```

---

### 2. 修复建议生成

```
请针对审计报告 reports/augmn/<repo-name>/latest/report.json 中的问题，生成详细的修复建议：

对于每个问题（按严重程度排序），提供：

1. **问题说明**
   - 规则名称和严重级别
   - 文件位置和行号
   - 问题描述

2. **修复方法**
   - 具体的修复步骤
   - 代码示例（修改前 vs 修改后）
   - 注意事项

3. **批量修复建议**
   - 哪些问题是同一类，可以批量修复
   - 推荐的修复顺序
   - 预估工作量

输出格式：Markdown，保存为 ai-fix-suggestions.md
```

---

### 3. 配置优化建议

```
请分析仓库 repos/augmn/<repo-name> 的结构和当前审计配置 .audit-config.yaml，生成优化建议：

1. **配置评估**
   - 当前配置是否合理
   - 是否有遗漏的检查项
   - 是否有不必要的检查

2. **规则优化**
   - 哪些规则应该启用/禁用
   - 严重级别是否需要调整
   - 是否需要添加自定义规则

3. **排除项优化**
   - 排除的文件/目录是否合理
   - 是否有应该排除但未排除的
   - 是否有不应该排除但被排除的

4. **建议的配置变更**
   - 具体的配置修改建议
   - 修改原因和预期效果

输出格式：YAML 配置建议 + Markdown 说明
```

---

### 4. 对比分析（多次审计）

```
请对比以下两次审计报告：
- 基线报告：reports/augmn/<repo-name>/<timestamp1>/report.json
- 最新报告：reports/augmn/<repo-name>/<timestamp2>/report.json

生成对比分析报告：

1. **问题数量变化**
   - 新增问题
   - 已修复问题
   - 持续存在的问题

2. **质量趋势**
   - 代码质量是提升还是下降
   - 哪些类别的问题改善最多
   - 哪些类别的问题恶化

3. **修复效果评估**
   - 之前的修复建议是否有效
   - 是否引入了新问题

4. **下一步建议**
   - 优先处理的问题
   - 需要关注的趋势

输出格式：Markdown
```

---

## 快速使用

最简单的使用方式：

```
请分析 repos/augmn/fe-casamiel-admin 的审计报告，告诉我主要问题和修复建议。
```

Claude Code 会自动：
1. 找到最新的 report.json
2. 读取并分析
3. 给出结构化的分析结果

---

## 批量分析

如果需要批量分析多个仓库：

```
请依次分析以下三个仓库的审计报告，并给出对比：
1. repos/augmn/fe-casamiel-admin
2. repos/augmn/be-promotion-center
3. repos/augmn/be-casamiel-applet-mall

对每个仓库：
- 生成问题摘要
- 给出修复优先级
- 评估代码质量

最后给出三个仓库的整体对比和建议。
```
