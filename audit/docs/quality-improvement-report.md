## 3. 新增功能

### 3.1 规则优先级机制（T105）

- ✅ 支持配置文件级规则覆盖：`.audit-config.yaml` 中的 `overrides.files`
- ✅ 支持 glob 模式匹配文件
- ✅ 支持 `severity: ignore` 忽略特定规则

**示例配置：**
```yaml
overrides:
  files:
    "src/legacy/**":
      rules:
        no-console: ignore
    "*.test.js":
      rules:
        no-console: ignore
```

### 3.2 误报标记功能（T106）

- ✅ 支持代码注释 `// @audit-ignore` 忽略特定行
- ✅ 支持多语言注释风格：
  - JavaScript/TypeScript: `// @audit-ignore` 或 `/* @audit-ignore */`
  - Go: `// @audit-ignore`
  - C#: `// @audit-ignore` 或 `/* @audit-ignore */`
  - Python/YAML: `# @audit-ignore`

**示例：**
```javascript
// @audit-ignore
console.log("debug"); // 不会被报告
```

### 3.3 规则文档生成（T107）

- ✅ 命令：`audit docs rules`
- ✅ 生成 22 条规则文档（ESLint 7 条、golangci-lint 8 条、dotnet-format 7 条）
- ✅ 输出到 `audit/docs/rules-reference.md`
- ✅ 包含规则说明、严重级别、修复建议、文档链接
